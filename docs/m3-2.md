# M3.2 Fixed performance controls

DINAD has seven fixed knobs and four fixed pads. The profile TOML assigns
semantic parameters to knobs and semantic actions to pads. Open F12 and
select **profile** to change the assignments. Save with Ctrl+S.

```toml
[knobs]
knob1 = "composition.tension"
knob2 = "transport.tempo_bpm"

[pads]
pad1 = "set composition.tension 0"
pad2 = "set composition.tension 2"
```

A profile with no knobs table uses the existing seven performance
parameters in their original order. A supplied table maps only the
listed slots. Pads are optional and accept set, adjust and undo. The
example profile maps three pads to tension levels and the fourth to undo.
Adjust a focused knob with the arrow keys or enter an exact value in its
display and press Enter. Each knob uses up to 1,000 positions. Use the
display for precision on wide ranges such as the random seed.
