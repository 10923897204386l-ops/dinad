# M3.2 Fixed performance controls

DINAD has seven fixed knobs and four fixed pads. The profile TOML assigns
semantic parameters to knobs and semantic actions to pads. Open F12 and
select **profile** to change the assignments. Save with Ctrl+S.

```toml
[knobs]
knob1 = "composition.tension"
knob2 = "transport.tempo_bpm"

[pads]
pad1 = "set composition.tension 0"
pad2 = "set composition.tension 2"
```

A profile with no knobs table uses the existing seven performance
parameters in their original order. A supplied table maps only the
listed slots. Pads are optional and accept set, adjust and undo. The
example profile maps three pads to tension levels and the fourth to undo.
The panel shows the active numeric value in a read-only digital display.
Use arrow keys on a focused knob for one-unit changes. Ctrl multiplies
the step by five, Shift by ten, and Alt by one hundred. For exact
values, edit the project TOML in F12.

## Live knob displays and tempo bounds (owner refinement)

- Each knob's associated digital display updates continuously as the dial is turned or dragged, with no save, focus loss, or editor round trip required.
- Display the *resolved current value* of the mapped semantic parameter, including updates from keyboard steps, pads, automation, project loading, and profile remapping. During dragging, provide immediate feedback; reconcile to the value accepted by the engine without leaving a stale optimistic reading.
- Format values according to the mapped parameter: tempo in whole-number BPM, percentages where appropriate, and sensible units/precision for other parameters. Remapping changes both the display label and value formatting.
- **transport.tempo_bpm: minimum 20, maximum 200, integer step 1 BPM.** Enforce bounds in the shared semantic parameter definition and validation path, not only the Qt dial; editor, commands, automation, and loading must use the same constraints. Clamp interactive knob movement at limits; invalid configuration should produce the existing validation feedback rather than silently change stored values.
- Preserve current keyboard modifier multipliers, with bounds applied to the final requested value.
