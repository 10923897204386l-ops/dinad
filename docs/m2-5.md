# M2.5 Release-aware arpeggio spacing

**Voice spacing 2** extends the M2.4 rule to releasing drone and pad
notes. DINAD uses a 300 ms window after drone note-off and a 400 ms window
after pad note-off, based on the SuperCollider envelopes. Mode **1**
uses gated notes only. Mode **0** plays the full fast arpeggio.

The estimates use elapsed seconds, so tempo changes do not stretch the
release windows. DINAD tracks releases even in modes 0 and 1, so switching
to mode 2 takes the current release windows into account. Saved takes
capture the resulting notes and rests.

For the listening check, compare modes 1 and 2 with both arpeggios
running. Listen around chord changes, where the old pad may still be
audible. The windows are a scheduling heuristic. They do not model
reverb, delay, or the actual tail of a third-party plugin.
