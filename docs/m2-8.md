# M2.8 Live controller schedules

Pass `--controller timeline.toml` to `dinad gui` or `dinad live`.
Use the same versioned beat-based set and ramp entries as the offline
timeline. A schedule runs once per Start. Beat positions between
half-beat onsets round up to the next onset, including across the
first cycle boundary. Same-onset entries keep their resolved order.

Scheduled updates go through DINAD's semantic controls and are
recorded with their requested and effective beats. A manual edit
takes effect at the next unscheduled onset. If a scheduled update
targets the same control at that onset, the scheduled value wins.
Stopping leaves the last control values in the panel. Starting again
restarts the schedule from beat zero.

For listening, load the M2.7 tempo ramp, then start playback. Listen for
the slowdown over the first eight beats and the steady tempo afterward.
