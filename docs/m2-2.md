# M2.2 seeded arpeggio motifs

Set **Arp motif** in the performance panel and press Enter, or set
`motif` under `[generation]` in project TOML.

- **0** retains the existing independent choices on each fast arpeggio step.
- **1** generates a four-beat motif from the seed and repeats it over the
  four chords, transposed to each chord root.
- **2** repeats the motif for the first three chords and plays its pitches
  in reverse order on the final chord.

Both motif modes draw from the current tension level's chord tones.
With evolution enabled, each 16-beat cycle uses the next seed. A live
change applies at the next unscheduled onset. Capture logs the semantic
change, and replay uses the resolved notes. Timing, the slow arpeggio,
and the sustained parts follow the same rules as M2.1.

For listening, try modes 0, 1 and 2 in the layered panel and let each
run for a full cycle. The repeated contour should be audible through
the chord changes. In mode 2, listen for the reversed last phrase.
