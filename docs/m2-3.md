# M2.3 evolving live form

Set **Form** in the performance panel and press Enter. The default
**0** plays all parts. **1** runs a repeating four-section form.
Each section lasts one 16-beat harmonic cycle.

| Section | Parts |
|---|---|
| 1 | Drone and pad |
| 2 | Drone, pad and slow arpeggio |
| 3 | All four parts |
| 4 | Drone, pad and fast arpeggio |

The form follows the running beat position. Changing it takes effect at
the next unscheduled onset and lets existing notes finish. Tempo changes
alter the duration in seconds. Seed evolution, motifs and tension continue
to shape each section. Saved takes replay the resolved arrangement.

Set `form = 1` under `[generation]` in project TOML to start in this
mode. The setting affects continuous performance. Single-cycle generation
and the finite timed-performance command still play their usual parts.

For the Fedora listening check, start in Form 1 and listen for all four
sections and the return to drone and pad. This takes about 32 seconds at
120 BPM. Switch to Form 0 and check that both arpeggios return.
