# M2.9 Controller schedule editor

Launch DINAD with `--controller timeline.toml` and open the editor
with F12 or backtick. Select **controller** from the document menu.
Stop playback, edit the schedule, and press **Ctrl+S**. DINAD validates
the whole schedule before replacing the file. A failed edit leaves
the current schedule and saved file intact.

Press Escape to return to the panel, then Start to run the new schedule.
A schedule loaded from the command line is editable. Create the initial
file before launch. This increment edits TOML schedules.
