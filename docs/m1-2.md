# M1.2 module registry and configuration

DINAD lists its built-in headless adapters and their declared capabilities,
parameter descriptions, dependencies, and limitations.

```sh
python -m dinad modules
python -m dinad validate-modules examples/first_environment/modules.toml
python -m dinad replay history.json --modules examples/first_environment/modules.toml
```

`replay`, `render`, and `play` accept a DINAD module TOML file via `--modules`.
Each operation may select a registered module by exact ID and version and
supply settings approved for its constructor. Omitted operations use their
existing defaults. Explicit `--sample-rate` and `--tail` override TOML settings
for audio operations. SuperCollider's read-only runtime settings can be set
at construction, including `preroll`. Playback still requires an exclusive
server and the existing `--exclusive-server` flag. Selecting SuperCollider for
`replay` stages events in that adapter without producing audio.

## Semantic mappings

Schema 1 accepts one or more target tables for a stable DINAD control ID
under `bindings`. Each target requires `module_id`, `module_version`, and
`native_id`, and may specify `scale` (default 1) and `offset` (default 0).
DINAD computes `value * scale + offset` and validates the mapping over the
full declared source range. Integer targets require integer-preserving
mappings. Each native target belongs to at most one source control.
A module swap changes the target declarations while preserving the
front-end control ID, such as `composition.anchor`.

`validate-modules` previews the resolved values for default project settings
or a project supplied with `--project`. Validation and preview use descriptors
and never instantiate an adapter. The shipped modules expose no writable
runtime parameters, so a mapping to either is rejected. Regression tests
exercise fan-out and swaps with explicitly registered fixture descriptors.
The preview is a value plan for later transport work. M1.2 does not deliver
parameter writes during playback or discover external plugins.
