# M3.1 Panel layout and readability

The panel groups controls under Transport, Performance and Takes.
Open F12, select **settings**, and set `[ui].text_scale` to `1.0`
or `1.25`. Ctrl+S validates and applies the change to the panel and
fixed-width editor immediately. DINAD saves it in the global
`dinad/settings.toml` under the user's configuration directory
(`~/.config` by default on Fedora).
