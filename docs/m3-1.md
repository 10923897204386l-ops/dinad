# M3.1 Panel layout and readability

The main panel groups controls under Transport, Performance and Takes.
Use **Text size** to switch between 100% and 125%. The setting applies
immediately to the panel and fixed-width configuration editor and is
saved per user through Qt settings. It is independent of project TOML
and works on top of the desktop's display scaling.

For the Fedora check, tab through the panel at both sizes, open F12,
and check that field labels, the editor and take controls remain usable.
Restart DINAD and check that it remembers the selected size.
