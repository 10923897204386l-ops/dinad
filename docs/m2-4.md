# M2.4 Voice-aware arpeggio spacing

Set **Voice spacing** to **1** in the performance panel and press Enter.
DINAD leaves a rest when a fast arpeggio note would sit one semitone
from a gated drone or pad pitch, regardless of octave. The rule includes
sustained voices starting on the same onset and excludes voices releasing
at that onset. The slow arpeggio and sustained parts keep their notes.

Set the control to **0** to restore all fast arpeggio notes. Changes apply
to future onsets. Saved takes contain the resolved notes and log the
control changes. The setting is also available as `voice_space` under
`[composition]` in TOML.

The check uses scheduled gates. It does not estimate release tails,
measure audio roughness, or apply to offline composition generation.

For the Fedora check, play Form 0 with both arpeggios and compare
spacing 0 and 1 across a full cycle. Listen for gaps in the fast line,
especially after the first chord, while the sustained parts continue.
