# M1.6 playable instrument evaluation

Use the [M1.5 Fedora setup](m1-5.md) to rebuild the headless helper and
install the verified LV2 bundle. Launch the DINAD panel from the repo root.

```sh
pw-jack python -m dinad gui \
  --project examples/first_environment/playable.toml \
  --profile examples/first_environment/controls.toml \
  --modules examples/first_environment/epiano.toml
```

The demo shares one harmonic context across the pad and two arpeggiators,
with a pedal drone below them. The fast arpeggio draws a new deterministic
variation each 16-beat cycle. The supplied project enables this with
`generation.evolve = true`. Existing projects retain the repeating pattern.

- **Ctrl+Space** starts or stops. **+ / −** move the shared anchor and map it
  to ePiano hammer hardness and treble boost. **F / S** change the tempo.
- **Backtick** or **F12** opens DINAD's configuration editor. **Escape**
  returns to the performance panel and keeps any draft in the editor.
  To explicitly route stereo,
  add `output_left` and `output_right` under `[operations.live.settings]`
  in the modules file. Use distinct JACK input port names, including their
  client prefixes. PipeWire may expose different names to JACK than it shows
  in `pw-link`. Omit both settings to use existing external graph routing.
  A missing configured port causes Start or Replay to fail visibly.
- Stop and enter a new JSON path in the take field. **Ctrl+Shift+S** saves
  the last performance. **Ctrl+Shift+P** replays the take at its recorded
  timing with its initial ePiano controls and automation. The current
  module config supplies the live helper, rate and routing.
- After stopping, inspect late events, playback xruns, startup xruns and
  the JACK graph DSP load at stop in the panel. DSP load is a point reading
  for the graph. The take also saves the original live diagnostics.

Live replay supports nonempty ePiano takes with compatible state and up
to an hour of recorded time and 100,000 notes. It leaves the current project and last
captured performance available for the next start or save. All parts
share one plugin instance and one stereo master. The take records
resolved notes and controls. For a WAV, use the M1.5 offline render path.

## Fedora listening check

Play through multiple cycles, change anchor and tempo, then stop, save
and replay. Listen for clear changes, usable volume, stuck notes and
dropouts. Check the stop diagnostics for both passes.

### Layered listening follow-up

The owner passed the offline SuperCollider pad and harmonic drone checks.
The original 65 Hz sine drone was inaudible on the test speakers. Adding
octave harmonics made the sustained note audible. The owner also passed
ePiano playback, save and replay in the original panel.

For a live layered check, add `--layered --exclusive-server --port 57110`
to the launch command above. Start a dedicated TCP-enabled SuperCollider
server first and route its stereo JACK outputs to the same sink as ePiano.
The layered panel sends drone and pad to SuperCollider and both arpeggios
to ePiano on the same transport. Reopen takes in layered mode to hear
that routing again. The offline render path remains single-backend.

The layered synth voices use a gentler attack at startup. With the demo
seed, the opening two arpeggio parts share a pitch and MIDI gate tracking
sends one note-on for that pitch. The owner confirmed the live drone is
audible and reported a click or doubled attack on the opening note.
Listening confirmation of the gentler attack is pending.
